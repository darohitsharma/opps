# Python Inheritance Class Notes

`oops 7th.ipynb` contains inheritance demonstrations followed by unfinished exercise prompts. The original repository and notebook names are preserved.

## Notebook map

- Cells 1-20 (one-based): executable examples of single, multilevel and multiple inheritance, inherited method calls and method resolution through class order.
- Cell 21: plain-language exercise prompts stored as code rather than Markdown. This cell raises `SyntaxError`; it is not an implemented assignment solution.
- Cells 22-23: empty code cells.

The early cells redefine `lecture`, `student` and `teacher` for separate demonstrations. Run those examples in order to establish the required classes and objects. Their printouts are learning examples, not application results.

## Read locally

Open the notebook in Jupyter or a notebook-capable editor using Python 3. The demonstrations use built-in Python, with no external package, dataset or service. The first twenty cells were executed in order during documentation review; the prompt cell was confirmed to be invalid Python. A full run-all will stop there.

This is class practice, not a finished banking or other application suggested by the prompts. No exercise solutions, test scaffolding or invented completion claims have been added. This README-only update preserves original code, prompts, saved outputs, filename and git history.
